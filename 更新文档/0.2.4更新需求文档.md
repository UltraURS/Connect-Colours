# Connect Colours 0.2.4 更新需求文档

整理日期：2026-10-26。

本文记录需求、用户已确认规则及实现进度。当前开发版本：0.2.4 测试版，构建号 17；已实现应用选择和最近任务过滤，本地验证结果见末尾，尚未通过真机验收。

## 更新目标

在模块应用的设置页面新增“隐藏类”分类，提供“隐藏后台软件”功能。点击后可选择需要隐藏的应用；勾选的应用在系统最近任务页面中不再显示任务卡片及底部对应的应用小图标，应用继续正常运行。

本文中的“后台页面”指参考图中的最近任务／多任务页面。

## 模块入口与应用选择

- 入口：Connect Colours → 设置 → 隐藏类 → 隐藏后台软件。
- 点击该项进入应用多选页面，可同时勾选多个应用。
- 列表展示应用图标、名称和勾选状态；可显示包名以区分同名应用。
- 初次使用时默认不勾选任何应用，不自动隐藏已安装程序。
- 勾选即保存，取消勾选即移出隐藏名单；再次进入选择页面时恢复已有选择。
- 名单在退出模块、重启手机及覆盖升级后保留，不因打开应用或创建新任务而失效。
- 界面沿用现有模块的背景、半透明卡片及控件风格。

## 隐藏行为

1. 勾选某应用后，隐藏其在最近任务页面中的全部任务卡片，包括已有任务和后续产生的新任务。
2. 同时隐藏最近任务页面底部与该应用对应的小图标，避免卡片消失后仍留下入口。
3. 按应用身份匹配名单，不依赖应用显示名称；未勾选应用正常显示。
4. 隐藏后重新排列可见卡片和底部图标，不保留空白占位、孤立图标或错位的点击区域。
5. 当所有任务均被隐藏时，显示系统正常的无可见任务状态，不出现残留卡片、异常滚动或崩溃。
6. 取消勾选后，在下次打开最近任务页面时重新显示该应用仍然存在的任务及对应图标。若任务已被系统或用户清除，不伪造或重新启动任务。

## 生效时机

- 勾选或取消勾选后，**下次打开最近任务页面即生效，无需重启手机**。
- 不要求在最近任务页面已经打开时立即实时刷新，但重新进入时不能继续使用过期名单。
- 名单同步不应要求用户为模块开启自启动或保持模块界面运行。
- 首次安装或启用 LSPosed Hook 所需的加载、作用域与重启步骤，在实际适配后另行说明；不影响后续名单修改无需重启的要求。

## 功能边界

- 仅改变最近任务页面中的展示，不能通过结束进程、强行停止、卸载、禁用应用或删除实际任务来达到隐藏效果。
- 被隐藏应用仍可从桌面或其他正常入口打开，原有后台运行和通知行为不因名单选择而被主动关闭。
- 桌面图标、应用列表及通知不属于本次隐藏范围。
- 不额外增加保活能力，也不把隐藏名单当作系统内存清理白名单；系统自身的后台管理仍然生效。
- 最近任务中的“清除”按钮保留原有系统语义；实现时需核验过滤展示不会造成清除对象错位或误操作。

## 实施前适配核查

- 分析当前 ColorOS 最近任务页面的任务列表、卡片绑定及底部应用图标来源；已有系统桌面 APK 为 `com.android.launcher` 13.0.44，可用于适配分析。
- 核验卡片和底部图标是否共用数据源，确保两处按同一名单过滤且不改变真实任务生命周期。
- 核验应用多任务、任务分组或分屏场景的归属，避免隐藏一个应用时连带隐藏未勾选应用。混合任务如无法按应用独立处理，应在开发时明确限制并与用户确认。
- 确认所需 LSPosed 作用域及进程，不提前假定仅新增模块设置即可生效。
- 确认名单的持久化和跨进程同步方式，确保下一次打开最近任务时读取最新配置。

## 验收要求

1. 模块设置中出现“隐藏类”及“隐藏后台软件”入口，可打开应用多选页面；初始名单为空。
2. 勾选一个正在运行的应用后，下一次进入最近任务，其卡片和底部图标均消失，无需重启。
3. 同时选择多个应用，所有选中应用都隐藏，未选中应用正常显示且点击目标正确。
4. 被隐藏应用仍可正常打开、运行和使用；重新启动该应用后进入最近任务，仍保持隐藏。
5. 同一应用存在多个任务时，全部对应卡片被隐藏，不留下底部图标或空位。
6. 取消勾选后，下次进入最近任务恢复仍存在的任务；已被系统清除的任务不会被重新创建。
7. 所有任务被隐藏、名单为空、退出模块及手机重启等情况下，最近任务页面均正常显示。
8. 滑动切换、点击任务、清除任务和“清除”按钮不出现错位、误操作或崩溃。
9. 原有 0.2.3 侧边栏手势、桌面回主屏等功能继续正常工作。

## 构建号 15 实现记录

- 新增“隐藏类 → 隐藏后台软件”多选入口，图标、名称、包名和选择状态一起展示；后台加载应用列表，列表复用行控件。初始名单为空，选择即时保存，读取失败和保存失败显示提示。
- 名单保存在现有 LSPosed 共享偏好中，与已有功能开关共存；不新增模块内容提供器、不依赖模块自启动。
- 新增“系统桌面”作用域 `com.android.launcher`，限定已核验的 13.0.44 / Android 13。在桌面读取新配置后使界面任务列表缓存失效，下次进入最近任务重新绑定。
- 在 `OplusRecentsViewImpl.applyLoadPlan` 展示入口过滤名单副本，卡片和底部 Dock 图标使用同一可见列表；不修改真实任务记录或源缓存，不调用删除任务、结束进程接口。
- 同时过滤 `showCurrentTask` 的前台任务占位路径，避免当前应用绕过列表过滤；空列表同步清理底部图标。
- 分屏组合仅一侧隐藏时创建单应用展示组，保留另一任务，原分组和任务对象不被修改。分屏点击和切换的真机效果仍需验证。
- 当前用户名单只匹配该用户的任务，同包名的工作资料、分身等其他用户任务保留；本版不提供跨用户选择。
- 为选择包含无桌面入口在内的已安装应用，声明 `QUERY_ALL_PACKAGES`；仅针对这项应用管理用途标注 Lint 局部例外，不全局关闭检查。

### 安装与验证

1. 覆盖安装 `dist/Connect-Colours-0.2.4-debug.apk`。
2. 在 LSPosed 的模块作用域新增勾选“系统桌面”，重启手机使 Hook 首次加载。
3. 打开模块 → 设置 → 隐藏类 → 隐藏后台软件，勾选应用后重新进入最近任务检查。
4. 取消勾选后再次进入最近任务，确认仍存在的卡片与底部图标恢复。后续名单变更无需重启。

本地测试覆盖名单保存及快照隔离、同名应用行复用、多任务过滤、两侧分屏组合、全部隐藏、不同用户同包名、前台占位任务及既有功能。原始 DEX 已核验桌面相关 18 项声明。尚未连接手机，跨进程即时读取、实际动画、分屏点击和清除按钮仍按上文验收要求验证。

本地构建结果：72 项测试通过（其中 35 项 Android 13 环境测试），Lint 0 错误、6 警告，APK 签名和 ZIP 对齐检查通过。真机状态：待用户验收。


## 构建号 16：应用列表搜索与勾选置顶

- 应用选择页面顶部新增“搜索应用名称”搜索栏，按名称包含关系即时筛选，支持中文，英文不区分大小写，忽略首尾空格。
- 已勾选应用排在列表最上面，选中和未选中组内沿用应用名称顺序；搜索结果同样遵循此规则。
- 勾选或取消勾选后立即保存并刷新排序；搜索期间未显示的应用仍保留原选择，清空搜索恢复完整列表。
- 无匹配项时显示“没有匹配的应用”。
- 本次只修改模块应用列表界面，覆盖安装后重新打开模块即可使用搜索和排序。
- 本地验证：73 项测试全部通过（含 36 项 Android 13 Robolectric 测试）；Lint 0 错误、6 项警告；APK 签名及对齐校验通过。尚未进行真机验证。


## 构建号 17：自定义侧边栏触发时间与分类合并（2026-10-29）

- 模块设置的功能类新增“侧边栏触发时间”滑块，可设置 0.2–1 秒，步长 0.1 秒，默认保持 0.5 秒。
- 保存后重启手机生效；仅影响滑到最大位移后的保持时间，未达最大位移不计时，回退清零，左右侧及桌面使用相同设置。
- 原“屏蔽类”和“隐藏类”合并为“隐藏类”，保留所有原有开关、隐藏后台软件入口及已保存配置。
- 本地验证：75 项测试通过（含 37 项 Android 13 Robolectric 测试），覆盖自定义计时、回退清零及滑块保存；Lint 0 错误、6 项警告，APK 签名和对齐校验通过。真机效果待验证。
